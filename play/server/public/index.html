PS1 Game Club

Play a PlayStation game you own with friends. Your disc stays on your computer: it is read by your browser and never uploaded.

1. Pick your disc

Choose a .chd, .pbp, .iso or a single .bin, or select a .cue together with all of its .bin track files (hold Ctrl or Shift, or Cmd on a Mac, to select several).

2. BIOS (optional)

Leave empty to use the built-in open BIOS replacement. Some games run better with a real PlayStation BIOS you dumped from your own console. It stays in your browser too.

3. Same game, same room list

Friends see each other's rooms only when they use the same game number. It is worked out from your disc. If you and a friend have different dumps of the same game (for example CHD and CUE/BIN), type the same number here.

How to play together

  1. Everyone opens this page, picks the same game and presses Start.
  2. When the game has loaded, open the Netplay button in the emulator's bottom bar.
  3. The host enters a name and picks Create a Room. Friends enter a name and press Join next to that room.
  4. The host is player 1. Joiners become player 2, 3 and so on, up to the number the game supports.

Netplay shares controller input. It only helps in games that already have a local two-or-more player mode. It does not turn a single-player game into a multiplayer one.

Bring your own legally owned games. No games or BIOS files are included or downloaded. Powered by EmulatorJS (GPL-3.0) and the PCSX-ReARMed core.
